> The one home for gaps that ship or travel past a step: minor review findings, excluded or failing acceptance criteria, `pre-existing` Definition-of-Done failures. Open rows are never copied into session logs, handovers or notes; those link here. Created at the first Ship that has a row; commit it with the feature.

| ID | Found in | Ref | Severity | Description | Status |
|---|---|---|---|---|---|
| KI-1 | `<feature-slug>` Step 4 | `<AC ID or file path>` | minor | <one line> | open |

`Severity` is `minor` (review finding) or `gap` (an AC excluded, failing, or not covered). `Status` is `open`, `fixed`, or `accepted` (the user decided to keep it; add the date in Description). A row is closed by setting its Status and adding the commit or PR in Description; rows are never deleted.
