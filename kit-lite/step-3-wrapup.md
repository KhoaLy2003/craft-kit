# Step 3 — Wrap-up

- **Gate**: `soft`
- **Produces**: `README.md`, final `docs/NOTES.md`

## Do

1. Run the full test suite and start the app once more. Fix anything that fails, with its own commit.
2. Write `README.md` (about one page): what it is, how to run it, how to test it, the stack. Commands must be copied from what you actually ran; prefer the project's `npm start` / `npm test` scripts over long one-liners.
3. Finish `docs/NOTES.md`: Status `complete`, stack and key decisions, remaining open issues, and the "Later" ideas. Delete finished task lists.
4. Commit `docs: readme and notes`.
5. Summarise in 3 to 5 lines: what was built, what was verified, what is open. Ask: "Anything to adjust, or call it done?" Advance unless the user objects.

## Rules

- Do not invent run or test commands. If a command was never run, do not put it in the README.
- No extra documents.

## Done when

The suite passes, the README exists, and `docs/NOTES.md` Status is `complete`.
